# Evolance v1.1 real study: pre-evaluation method

Registered before comparative performance calculation; no post-hoc tuning.
Traditional: trailing 252-session cumulative portfolio return > 0 AND Sharpe > 0 => Bullish; both < 0 => Bearish; otherwise Neutral / Uncertain. Reuse existing traditional_direction, not a new optimized baseline.
MC-only and Evolance use identical frozen distributions, probability bands and median guardrails. Directional equality is expected. MC-only confidence excludes structural adjustments.
Five portfolios: equal 0.3333/0.3333/0.3334; concentrated 0.70/0.15/0.15; AAPL, MSFT, NVDA singly. All share the same four-symbol intersection and SPY benchmark; fixed weights rebalance daily, no costs.
252 return lookback, completed calendar month end, 126/252 future sessions. Generate all signals before outcomes. Incomplete terminal windows remain unavailable. Risk-free assumption remains frozen 4%.
Hit denominator: complete Bullish/Bearish only; zero realized return is a miss. Neutral coverage reported over both all signals and complete windows. Confidence outcome statistics use directional complete predictions only; state/transition/flag groups include neutral complete outcomes. Sample std uses ddof=1.
All portfolio-specific and pooled summaries retained. Pooled portfolios are correlated and horizons overlap; no independent-sample significance claim. No naive IID bootstrap or predictive superiority claim. Groups with fewer than 20 complete observations marked insufficient evidence (reporting convention only).
Interpretation pairs: same date, same horizon and same MC direction, different state/flags/transition, P(up) difference <=0.05. Retain ALL matching pairs. Structure severity for case auditing only: flag count +1 for Deteriorating +1 for Stressed. Higher-severity side has worse future drawdown by >0.02 => useful association; opposite => misleading; otherwise redundant. This post-signal audit does not change scores. Show earliest case of each category plus full table, not only successes.
Failure audit: all bullish losses, bearish gains, high-confidence misses, Recovering losses, Deteriorating with future drawdown better than -0.05 (operational false-alarm proxy), and non-Deteriorating with future drawdown <=-0.20 (operational missed-deterioration proxy). These audit thresholds are not framework rules or trading recommendations.
Calendar: common five-day gaps 2006-12-29 to 2007-01-03 and 2012-10-26 to 2012-10-31 are consistent with weekend/New Year/Ford mourning closure and weekend/Sandy closures. All four assets agree. No online verification or local authoritative calendar is available: attribution remains unverified, non-blocking, disclosed. No prices filled or edited.
Raw inputs remain private; exports are explicit derived-field allowlists. Preserve frozen source and previous artifacts byte-for-byte.
